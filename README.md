# Best Cars Dealerships

## Project Overview
Best Cars Dealerships is a full-stack web application for browsing car dealerships, viewing dealership details and customer reviews, and submitting reviews.

## Technologies Used
- Frontend: React, HTML, CSS, Bootstrap
- Backend: Django, Python, Node.js, Express
- Database: MongoDB
- Deployment: Docker, Kubernetes, GitHub Actions

## Features
- User registration, login, and logout
- Browse dealerships and filter dealerships by state
- View dealership details and customer reviews
- Submit reviews and analyze review sentiment

## Project Structure
- `server/frontend/` — frontend application
- `server/djangoapp/` — Django application
- `server/database/` — database and Node.js backend
- `server/djangoproj/` — Django project configuration
